# Robotics classroom projects

- [SPIKE Prime with VS Code and Pybricks](spike-prime/README.md): install the tools, create a virtual environment, and upload the first programs to a physical robot.
- [Git practice lab](START-HERE.md): practice commits and branches with a pretend robot mission.

Open the `spike-prime` folder itself in VS Code when following the Pybricks lesson. This loads that project's interpreter settings and run tasks.
